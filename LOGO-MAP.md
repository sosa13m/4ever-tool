# 4EVERTOOLS — Mapa de logos

La web usa las versiones `.webp`. Están recortadas al borde visible del dibujo, y cada theme guarda su proporción (`logoRatio`) en `src/data/themes.ts`. Los logos que la web no usaba (versiones viejas y los `.png` originales) se sacaron del proyecto; quedaron guardados en `logos-sin-uso-respaldo.zip`, que no se sube a GitHub.
